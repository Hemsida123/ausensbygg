# Åsens Bygg – ny webbdesign

18 sidor med sju tjänsteområden, fyra referensgallerier, företagspresentation, kontakt, planeringsguide och integritet. Vit design med mörkgröna detaljer och originalets svarta logotyp. Företagsnamnet är Åsens Bygg; domänen är ausensbygg.se.

## GitHub Pages
Lägg innehållet i ausensbygg-github i repots rot. Aktivera Pages från huvudgrenen och rotmappen. ## Verifiering
18 sidor vid 1440, 390 och 320 pixlars bredd, totalt 54 kontroller utan överflöde eller trasiga bilder. Mobilmeny, Escape, projektfilter, bildförstoring, piltangenter och kontaktförval har provats. Axe på fem representativa sidtyper gav inga WCAG A/AA-överträdelser. Representativa sidor är kontrollerade i Chromium och WebKit. Lokal Lighthouse-mätning för mobil: 99 prestanda, 100 tillgänglighet, 100 best practices och 100 SEO. Det är lokala testresultat, inte garantier för framtida drift.

## Drift
Statisk HTML, CSS och JavaScript utan ramverksberoenden. Ingen autoplay, parallax, rullningslyssnare, analyskod eller externa typsnitt. Manrope hostas lokalt enligt medföljande SIL Open Font License. Uppdatera canonical, Open Graph, sitemap och robots vid slutlig domänpublicering.
